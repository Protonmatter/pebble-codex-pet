# Security Policy

## Supported versions

Security and integrity fixes are applied to the latest tagged release and the
`main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository.
Do not open a public issue for an unpublished vulnerability.

Include the affected file or release, reproduction steps, expected impact, and
any suggested mitigation. Reports will be acknowledged after triage; timelines
depend on severity and reproducibility.

## Release integrity

Tagged releases are built from committed source, checked against the committed
runtime assets, packaged deterministically, and published with SHA-256 checksums
and GitHub build-provenance attestations.
